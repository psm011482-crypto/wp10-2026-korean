# Winning Post 10 2026 한국어 패치

Windows Steam판 **Winning Post 10 2026 v1.0.4.0**용 비공식 한국어 패치입니다.

## v0.7.0-beta 안내

**v0.7.0-beta 소개와 설치 안내를 먼저 공개합니다. 배포 ZIP은 업로드 예정이며, 아직 이 버전의 다운로드 파일은 등록되지 않았습니다.** 업로드가 끝나면 이 안내에 다운로드 링크를 추가하겠습니다.

- **[v0.7.0-beta 업데이트 안내](RELEASE_NOTES_v0.7.0-beta.md)** — 주요 개선점, 알려진 문제, 개발 상황
- [배포 파일 목록](https://github.com/psm011482-crypto/wp10-2026-korean/releases)
- [이전 v0.6 통합수정4 테스트판](https://github.com/psm011482-crypto/wp10-2026-korean/releases/tag/v0.6-unified-hotfix4) — 구버전 설치법은 해당 Release를 확인하세요.

이번 버전은 대화 Auto 진행 속도, 가상마·유구마의 한글 마명 표시, 경주 중계 멘트 한글화를 중심으로 보강했습니다. 일부 일본어와 어색한 번역, 화면별 이름 표시 문제는 남아 있습니다. **전체 한글화와 모든 게임 구간 검증이 끝난 완성판은 아닙니다.**

## 설치 전 확인할 알려진 문제

### 코스포 페이지 전환 지연·실패

코스포 일부 페이지에서 전환이 크게 느려지거나 다음 페이지로 넘어가지 않는 현상이 있습니다. 실제 플레이에서는 10페이지 이후 일부 구간, 특히 **16→17 및 26·27쪽 부근**에서 확인됐습니다.

취소키를 여러 번 눌러 메뉴에서 빠져나온 뒤 게임을 계속 진행한 사례가 있지만, 모든 환경에서 같은 방법으로 복구된다고 보장하지 않습니다. **v0.7.0-beta에서 미해결이며 원인은 확인되지 않았습니다.**

### 말 계통확립 시 SP/ST 특성 문제

일부 말의 계통확립 시 기대한 **SP/ST 특성 대신 무계로 적용된다는 사용자 제보**가 있습니다. 제보에는 파흘슬론, 레이즈 어 네이티브, 테스코보이가 사례로 언급됐습니다.

**해결된 문제가 아닙니다.** 원인·발생 조건·영향 범위와 v0.7.0-beta에서의 재현 여부는 아직 확인하지 못했습니다. 제보 사례가 영향받는 말의 전체 목록이라는 뜻은 아닙니다. 커뮤니티에서 제시된 우회 방법도 검증된 해결책으로 보장하지 않습니다.

[기존 안내 글과 계통확립 관련 제보](https://gall.dcinside.com/mgallery/board/view/?id=winningpost&no=8830&page=1)

중요한 세이브는 설치 전 별도로 백업해 주세요. 일부 대화·코스포 기사·이름·경마사전·조교 해설·History/장문에는 일본어 또는 혼합 출력이 남아 있습니다.

## v0.7.0-beta 설치·실행

아래 파일명과 절차는 **v0.7.0-beta용**입니다. 구버전 파일과 섞지 마세요.

요구 사항은 Windows, Steam 정품, 게임 실행 파일 버전 **1.0.4.0**입니다. 설치기는 실행 파일과 게임 데이터의 해시를 검사하므로 업데이트된 다른 파일에는 설치가 거부될 수 있습니다. Python 등 실행 환경은 패키지에 포함됩니다.

### 처음 설치하는 경우

1. 중요한 세이브를 백업하고 게임과 실행기를 완전히 종료합니다.
2. ZIP 전체를 별도 폴더에 풉니다. **게임 폴더 안에 넣을 필요는 없습니다.** 폴더 구조를 유지해 주세요.
3. `02_Install.cmd`를 실행합니다.
4. **`04_Run_With_F8_Capture.cmd`로 실행하는 것을 권장합니다.** 캡처가 필요 없으면 `03_Normal_Run.cmd`를 사용합니다.

Steam이나 게임 EXE에서 직접 실행하면 동적 번역이 적용되지 않습니다.

### 기존 패치를 업데이트하는 경우

1. 게임과 기존 패치 실행기를 완전히 종료합니다.
2. **기존 패치 폴더의 설치 상태·원본 백업·로그를 보관한 채** 새 패키지를 기존 폴더 옆에 풉니다. 기존 폴더에 덮어쓰지 마세요.
3. 새 패키지의 `01_Remove.cmd`로 기존 설치를 제거합니다.
4. **제거 성공을 확인한 뒤** `02_Install.cmd`를 실행합니다.
5. `04_Run_With_F8_Capture.cmd` 또는 `03_Normal_Run.cmd`로 실행합니다.

이전 패키지를 찾지 못하거나 여러 설치가 검색되면 다음처럼 경로를 지정할 수 있습니다.

```bat
01_Remove.cmd --previous "이전 패키지 폴더의 전체 경로" --game "게임 폴더의 전체 경로"
```

원본 백업이나 설치 파일의 검증에 실패하면 제거가 거부됩니다. 오류를 무시하고 새 설치를 진행하거나 강제로 덮어쓰지 말고 [Issues](https://github.com/psm011482-crypto/wp10-2026-korean/issues/new/choose)에 알려 주세요. 기존 사용자 지정 한글 마명 기록을 이어 쓰려면 이전 폴더의 로그도 보관해야 합니다.

게임 자동 탐색이 실패하면 설치·실행 파일 뒤에 `--game "게임 폴더의 전체 경로"`를 지정할 수 있습니다. 자세한 안내는 패키지의 `README_KO.md`에 있습니다.

### 제거

게임과 실행기를 종료한 뒤 `01_Remove.cmd`를 실행합니다. 검증된 원본을 복원하며 세이브 파일을 삭제하지 않습니다. 설치 상태·백업은 제거가 완료될 때까지 보관하고, 필요한 로그·사진·사용자 마명 기록은 별도로 보관해 주세요.

## F8 화면 저장과 제보

`04_Run_With_F8_Capture.cmd`로 실행하고, 일본어·오역·이름 표시 문제·버벅임이 보이는 화면에서 **F8**을 눌러 주세요.

- 저장 위치: 패치 폴더의 `logs/f8_capture/captures/세션/`
- 저장 내용: PNG 화면과 대응 JSON 정보
- 게임 창이 앞에 있고 실행 세션이 연결된 상태에서 사용합니다.
- 캡처 총량이 500MB를 넘으면 필요한 기존 사진을 다른 곳에 보관한 뒤 다시 실행해 주세요.
- 캡처와 로그가 모든 화면 문자열을 빠짐없이 기록하는 것은 아닙니다.

제보는 **[GitHub Issues](https://github.com/psm011482-crypto/wp10-2026-korean/issues/new/choose)**로 받습니다. 버전, 문제가 발생한 화면, 발생 순서, F8 사진과 관련 로그를 함께 남겨 주세요. 공유 전에 사용자 이름 등 개인 정보가 포함됐는지 확인하고, 실제 세이브 파일은 공개 첨부하지 마세요.

## 게임 업데이트와 파일 확인

게임 업데이트·재설치·Steam 무결성 검사 전에는 가능하면 패치를 먼저 정상 제거해 주세요. 이후 게임 파일이 달라졌다면 호환 여부를 확인해야 합니다.

배포 예정 ZIP은 `WP10_2026_Korean_v0.7.0-beta.zip`이며, 크기는 **155,345,916 bytes (약 155.35MB)**입니다. 업로드 후 함께 제공되는 SHA-256 파일로 다운로드를 확인할 수 있습니다.

```text
58361DCA15D0EED3B8525A64BACA5BEE8B1411C032E422D9A13584CBD8318953
```

## 고지

- 비공식 팬 번역이며 코에이 테크모와 무관합니다.
- Steam 정품이 필요하며 원본 게임 EXE·DATA와 세이브 파일은 배포 ZIP에 포함하지 않습니다.
- [Pretendard](https://github.com/orioncactus/pretendard) 및 포함 실행 환경의 라이선스는 패키지에 보존돼 있습니다.
- 전체 구간 실플레이와 다른 PC의 동작을 모두 검증한 상태는 아닙니다.
